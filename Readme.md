# Language Translator

This is a simple Language Translator web application built as part of my internship at **CodeAlpha**.

## Features
- Translate text from English to Hindi
- Copy translated text to clipboard
- Text-to-Speech (Speak the translated text)
- Swap text between input and output
- Clean and responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
